# Analizador de logs para SOC

Proyecto personal que estoy empezando durante la especialización de ciberseguridad. Quiero crear una herramienta sencilla en Python para leer logs de autenticación, agrupar intentos fallidos por IP y señalar patrones que merezcan una revisión.

## Estado actual

**En desarrollo — fase inicial.** Este primer paso añade la página de presentación y define el objetivo del proyecto. El analizador en Python todavía no está implementado.

Antes de programarlo voy a estudiar los formatos de los logs y los datos que contienen, y a definir qué revisará la primera versión. Quiero entender los eventos para poder explicar las reglas de análisis y tener en cuenta los errores de acceso normales.

## Siguiente paso

Elegir un formato de log, preparar ejemplos de prueba y empezar con un script que lea el archivo. Iré añadiendo las funciones y documentando los avances poco a poco.
