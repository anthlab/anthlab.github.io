    03 / REDES IPv4 Disponible

    IP y subredes.

    Clasifica una IPv4 y calcula su máscara, red, broadcast y rango de hosts.

    Datos de entrada

    01

    Solo IPv4. Todo se calcula en tu navegador, sin consultas externas.

    Resultado

    02

    Introduce los datos para empezar.

    CÓMO FUNCIONA

    Direcciones IPv4 y bits de red.

    01

    Revisa la dirección

    Cada IPv4 tiene cuatro octetos de 8 bits. Se comprueba el formato y se compara con algunos rangos privados y especiales.

    02

    Calcula la red

    El prefijo indica los bits de red. La operación IP AND máscara conserva esos bits y pone a cero los de host.

    03

    Obtiene el rango

    En una /24 hay 256 direcciones y 254 hosts. Para /31 se aplica el caso de enlaces punto a punto; /32 es una sola dirección.

    La clasificación es básica: quedar fuera de los rangos identificados no garantiza que una IP sea pública utilizable. No consulta ubicación, propietario, reputación ni conectividad.

    04 / DIRECCIONES WEB Disponible

    Analizador de URLs.

    Separa las partes de una dirección y señala algunos detalles para revisar.

    Dirección para analizar

    01

    Empieza por http:// o https://. Se analiza el texto sin visitar la web.

    ↳

    Todo se queda en tu navegador

    No abre el enlace, no descarga contenido y no consulta servicios externos.

    Resultado

    02

    Introduce una URL o prueba el ejemplo.

    Los avisos no confirman que una web sea peligrosa. Que no haya avisos tampoco garantiza que sea segura, aunque use HTTPS.

    CÓMO FUNCIONA

    Lee las partes antes de abrir un enlace.

    01

    Separa la dirección

    Usa la API URL del navegador para leer protocolo, host, puerto, ruta, consulta y fragmento.

    02

    Señala detalles

    Busca HTTP, datos antes de @, IPs en formatos alternativos, punycode y puertos distintos del habitual. Los caracteres codificados se muestran como información.

    03

    Muestra el destino

    El host se muestra como texto. No consulta DNS, reputación, redirecciones ni el contenido de la web.
